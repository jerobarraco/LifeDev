# Interact

Unreal plugin to handle interactions and simple animations.
Intuitively, easily, powerfuly!

Usable from BP and CPP.

Can be extended and overriden for your custom needs.

I've added documentation on all the objects, so you can read the tooltips on the engine. Or read the code.

It's FOSS (free and opensource). I'll be updating the docs with time.
