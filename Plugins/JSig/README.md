# JSig

Plugin to handle significance very easily on unreal engine 5.

Easy to use system for optimizing your game.

Usable from BP and CPP.


Allows you assign a significance to actors and components, and perform actions based on that significance. (See CSignificance)


By default, it can adjust tick intervals, visibility, de/activation of components, and others.

By default, it does so based on distance to the player, occlusion, and others.


But anything can be extended and overriden for your custom needs.
You can use it to adjust any property, or trigger any action, for any reason.

I've added documentation on all the objects, so you can read the tooltips on the engine. Or read the code.

It's FOSS (free and opensource). I'll be updating the docs with time.
